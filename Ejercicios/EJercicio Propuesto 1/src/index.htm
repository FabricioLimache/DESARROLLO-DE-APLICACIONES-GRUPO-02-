Proyectos personales

Curso y análisis de redes en una empresa

Como parte de mi formación participé en una visita a una empresa para realizar un curso relacionado con redes. Esta experiencia me permitió observar una infraestructura empresarial y analizar cómo los conocimientos de redes pueden utilizarse para mejorar diferentes procesos tecnológicos.

Simulación de red con Cisco Packet Tracer

Desarrollé una simulación de infraestructura de red utilizando Cisco Packet Tracer. El proyecto permitió representar una posible solución de red y comprender mejor la comunicación entre los diferentes dispositivos de una organización.

Diario de ingeniería y propuesta de mejora

Elaboré un diario de ingeniería basado en la experiencia de la empresa visitada. En este trabajo documenté observaciones y propuse diferentes formas de mejorar su infraestructura mediante la aplicación de conocimientos relacionados con redes.

Software de simulación de órdenes de compra

Desarrollé un software destinado a simular el proceso de una orden de compra. Este proyecto me permitió trabajar con lógica de programación y representar digitalmente un proceso relacionado con el funcionamiento de una empresa.

Aplicación personal de música

Desarrollé una aplicación de música para uso personal. La aplicación permite integrar y reproducir archivos de música almacenados en mi propia computadora. Se trata de un proyecto privado, creado con fines personales y de aprendizaje, y no funciona como una plataforma pública de distribución de música.
